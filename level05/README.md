# Level 5 — Advanced RAG Foundations (Projects 71–75)

All projects are standard-library prototypes, not production RAG systems. Keyword ranking is not semantic retrieval, and pattern checks do not guarantee prompt-injection protection.

- 71: local `.txt`/`.md` keyword search
- 72: transparent keyword-overlap chunk ranking
- 73: extractive answer draft with source IDs
- 74: evaluation dataset validation and Recall@k
- 75: common prompt-injection phrase checker

Run from repository root: `python -m unittest discover -s level05 -p 'test_*.py' -v`
