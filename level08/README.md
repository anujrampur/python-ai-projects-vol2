# Level 8 — AI Automation Foundations (Projects 86–90)

These projects are safe, offline foundations using the Python standard library. They do not send email, move files, run arbitrary commands, browse the web, or call an LLM.

- **86 Email Draft Builder:** creates editable drafts only.
- **87 Smart File Organizer:** produces a dry-run move plan; no filesystem changes.
- **88 Workflow Engine:** executes only three allowlisted string transformations.
- **89 Research Report Pipeline:** formats user-provided source notes and includes verification reminders.
- **90 Productivity Planner:** schedules tasks by priority within a time budget.

Run tests: `python -m unittest discover -v` from this folder.
