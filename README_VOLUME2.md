# Python + AI Projects — Volume 2 (Projects 51–100)

This repository tree contains the working source code and tests for Projects 51–100, organized into ten levels. Most projects are deterministic/offline educational prototypes. A project name containing “AI” does not imply that a live LLM or pretrained model is bundled. Check each level README and project docstrings for dependencies and limitations.

## Run tests
Run from each `levelNN` directory: `python -m unittest discover -v`. Tests were executed separately per level in the current packaging check.

## Safety and publication status
This is a source-code working bundle, not a claim of publication-ready book files. Review project behavior, manuscript alignment, optional dependency integrations, licensing, and book layout before release. Projects 96–100 include their level manuscript in `level10/`; project 91–95 manuscript is in `level09/`; earlier level manuscript fragments are under `book_manuscript/`.
